# Test Fixtures

Sample files covering every format the Dark Document Viewer supports, for manual testing via the viewer's "Open file" button.

- `sample.pdf` — minimal single-page PDF (Smart Dark / Invert / Sepia / Original)
- `sample.docx` — title, headings, bold/italic runs, a bulleted list
- `sample.pptx` — 3 slides with bold/italic text
- `sample.txt` — plain text
- `sample.md` — headings, bold/italic, inline code, a bulleted list
- `sample.rtf` — minimal RTF

All generated programmatically (no real Office/Adobe installation used) — see git history for the generator scripts if you need to regenerate or extend these.
