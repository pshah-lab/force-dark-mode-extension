Support & Troubleshooting

Find quick answers to common questions, learn how to resolve display issues on specific websites, or file a bug report.

Troubleshooting Common Scenarios

A site looks inverted or weird in Auto Mode

While the Auto Engine works automatically for 98% of sites, image-dense or unconventional layouts might benefit from switching engines:

  1. Click the ThemeSwitcher icon in your browser toolbar.
  2. Select CSS Engine if images or diagrams look distorted.
  3. Or select Invert Engine if the page has embedded canvas widgets.
  4. Your choice will be saved exclusively for that domain.

A website already has a dark mode

ThemeSwitcher’s Auto Engine automatically identifies sites with active dark themes (like YouTube, GitHub, or Reddit in night mode) and avoids double-styling. If you want to disable ThemeSwitcher completely for a specific site, simply click the extension icon and switch the toggle to Off.

How to read local PDF files in dark mode

  1. Click the ThemeSwitcher icon in your toolbar.
  2. Click the Open file viewer button at the bottom of the popup.
  3. Click Choose File and select any PDF, TXT, or Markdown document from your computer.
  4. The document will open in an offline, eye-soothing dark reader.

Reporting Bugs & Suggesting Features

ThemeSwitcher is community-driven and actively maintained. If you discover a broken website, visual glitch, or have an idea for an enhancement:

  • GitHub Issue Tracker: Submit a detailed report with the website URL and screenshot at github.com/pshah-lab/force-dark-mode-extension/issues.
  • Feature Requests: Use our GitHub Discussions or open a Feature Request issue.

Uninstalling ThemeSwitcher

You can remove ThemeSwitcher at any time:

  1. Right-click the ThemeSwitcher icon in your Chrome toolbar.
  2. Click Remove from Chrome...
  3. Confirm removal in the dialog. All per-site data stored in Chrome Sync will be removed.
