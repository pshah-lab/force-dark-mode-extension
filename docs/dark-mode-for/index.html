Dark mode for popular sites

Each guide shows real before and after screenshots taken with ThemeSwitcher, names the engine that was used, and says what changes and what doesn't. We only publish a guide once we have screenshots of the site.

  • Dark mode for ExamTopics: an ExamTopics exam question page (AWS Certified Cloud Practitioner CLF-C02, Topic 1), CSS Engine.
  • Dark mode for Notion: Notion's public marketing homepage (not the Notion workspace app), CSS Engine.
  • Dark mode for YouTube: the YouTube homepage feed, Auto Engine.
  • Dark mode for LeetCode: the LeetCode Two Sum problem page, signed out, CSS Engine.
  • Dark mode for Wikipedia: the English Wikipedia article "Dark mode", logged out, Auto Engine.
  • Dark mode for GitHub: a public GitHub repository page (this project's own), logged out, Auto Engine.
  • Dark mode for Hacker News: a Hacker News comment thread (item 8863, from 2007), Auto Engine.

Not listed? ThemeSwitcher works on any site. Open the side panel and pick an engine. If a page looks wrong, press Report this site as broken; it sends only the domain, engine, theme label and version, and only after you confirm.

See also: how to force dark mode in Chrome, dark mode for PDFs and ThemeSwitcher vs Dark Reader.
