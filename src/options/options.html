    Custom CSS

    Add your own CSS for one site. It is applied after the dark theme, only on that site (applied only while dark mode is on for that site).

    Use the host exactly as it appears in the address bar, without https:// or a path. For example, www.example.com and example.com are different sites.

    0 / 6000

    Custom CSS cannot introduce a URL: url(), @import, @font-face, image-set() and escape characters (backslashes) are blocked. The extension itself never makes network requests.

      Privacy by Design

      Privacy & Data Management

      ThemeSwitcher is local-first. All preferences are stored strictly inside your browser profile via chrome.storage.sync. No browsing history, page contents, or documents ever leave your device. The only optional exception is the anonymous usage report above, which is off unless you turn it on.

      Export your saved dark mode configurations as a portable JSON file, or restore them on another machine.
