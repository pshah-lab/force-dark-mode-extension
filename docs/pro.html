ThemeSwitcher Pro (coming soon)

Pro is under consideration, not committed. Nothing here is final, and the free extension is not changing.

What stays free

The core dark mode extension, the document viewer, Export and the PDF tools stay free.

What Pro might add

We are considering Pro for heavier tools. This is a list of ideas, not a promise:

  • PDF compression
  • True redaction
  • Signing and filling forms
  • Tool chains with saved presets
  • Higher page and size limits
  • Later, OCR (scanned PDFs to searchable text)

All of it would run on your device, like everything else in ThemeSwitcher.

How licensing might work

The current plan is one licence key per year, which the extension checks offline. This plan is not final.

Privacy

Nothing about this page changes the extension's privacy promises. The extension collects nothing for Pro. If you email us, we only receive what you write in that email.
